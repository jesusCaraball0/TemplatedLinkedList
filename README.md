# Templated Linked List
## Description
Built a fully functional templated linked list using C++. Implemented constructor, destructor, copy assignment operator, insertion (at head, tail, before a node, after a node, and at an index) of single and multiple nodes, and removal (at head, tail, index, or based on value) of single and multiple nodes. Behaviors include displaying the list forwards and reverse (with and without recursion), finding a node based on its content, and find all nodes with a specific value. Indexing, assignment, and equality operators are overriden to work for a linked list. Main file contains extensive test cases for all functions. 
## Install Instructions
Project does not have any dependencies. After forking, it can be ran locally using an IDE, Makefile, or terminal.
